Department Of Computer Science & Engineering - AIML

Introduction

Welcome to the B.Tech Computer Science & Engineering - AIML Course Curriculum. This curriculum provides students with knowledge of programming, artificial intelligence, machine learning, data structures, web development, cloud computing and deep learning.

Semester 1 Subjects (Ordered List)

  1. Artificial Intelligence Fundamentals
  2. C++ Programming
  3. Web Designing
  4. Kaggle Basics

Semester 2 Subjects (Ordered List)

  1. Data Structures using C++
  2. Advanced Programming
  3. Kaggle Skill Development

Semester 3 Subjects (Ordered List)

  1. Operating Systems
  2. Python Programming
  3. Data Visualization
  4. Object Oriented Programming using Java
  5. Advanced Data Structures & Algorithms
  6. AWS Fundamentals
  7. Full Stack Development
  8. GitHub

Semester 4 Subjects (Unordered List)

  • Database Management Systems
  • Design & Analysis of Algorithms
  • Artificial Intelligence
  • Computer Organization & Architecture
  • CodeChef Practice
  • GitHub Practice

Semester 5 Subjects (Description List)

Theory of Computation
Study of formal languages, automata, grammars and computational models.
Machine Learning & Neural Networks
Introduction to machine learning algorithms, neural networks and predictive models.
Artificial Intelligence
Study of intelligent systems and AI-based problem solving.
Computer Networks
Fundamentals of computer communication and networking.

  4. AWS Certification

  • Semester 8 - Major / Capstone Project
